# The Role of Movement and Design in Character Perception
This project explores how people connect with a digital character through **how it looks and how it moves**. Instead of using many characters, one character will show five emotions: **joy, sadness, anger, disgust and fear**, using different **colours, shapes, and movements**.
While emotions are often shown through visual design, like colour and shape, theories of embodied cognition suggest that we also understand emotions through **our body and movement**. To guide this, the project uses **Laban Movement Analysis (LMA)**, linking specific movement qualities to each emotion. Based on this, the project also aims to create a simple **framework that connects emotions to LMA movement qualities**, making it easier to design expressive characters.
The study looks at whether people rely more on what a character **looks like** or how it **moves**, especially when these do not match. It has two stages: first, people watch and rate the character; second, they **become the character** by moving like it.
By comparing these stages, the project aims to find out whether **visual design or movement feels more real and creates a stronger emotional connection**.
### Research question
How does the conflict between visual appearance and movement cues influence perceived personality, and does this influence change after embodiment?
